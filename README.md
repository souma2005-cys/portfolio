# Cybersecurity Portfolio

A responsive, dependency-free cybersecurity portfolio for Souma Deep Pal, built with HTML, CSS, and JavaScript.

## Preview

Open `index.html` directly, or run any static server from this folder. For example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Included profile data

The site includes information from Souma's CV:

- Security Admin Associate L1 internship
- MY Bharat 120-hour cyber awareness program
- Cyber Security education and SGPA
- Python antivirus scanner and packet sniffer / ARP detector projects
- Skills, contact information, GitHub, LinkedIn, and downloadable CV

The interface also includes a boot sequence, switchable color spectra, animated telemetry, holographic radar, 3D tilt cards, project dialogs, and an interactive terminal.
